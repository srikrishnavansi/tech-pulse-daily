Spielewoy/autoprompt-skill

A Claude Code / Codex skill that runs the full loop — scope, implement, test, review, repair — from one goal, constraints and success criteria, stopping only for decisions that change the outcome, actions needing your authority, or blockers it can't resolve safely. Its README claims a 45% cut in agentic task failures — that's the maintainer's own number, no benchmark data or comparison published.

Why it matters: This is the shape we'd want for our own Claude Code skills: an autonomous loop that knows when to stop and ask instead of over-asking or silently barreling through. Worth reading even if we don't adopt it as-is.

Newest tools

show hn

getkern/kern

A rootless, daemonless container/sandbox runtime — one 1.52MB static binary that spins up a real kernel-enforced container (namespaces, seccomp allowlist, cgroup v2 limits) from an OCI image in ~3.5ms. Ships a kern-sandbox wrapper specifically for running agent- or LLM-generated code in isolation: network off, memory/pid caps, capabilities dropped, output bounded, timeout enforced.

This is exactly the shape of thing you'd reach for to sandbox a RealGenie agent's generated code or shell commands without standing up Docker. Worth a spike before hand-rolling another subprocess jail.

JetBrains Junie Local (Qwen3.6-27B)

Junie Local runs Qwen3.6-27B on-device with one command, skipping manual Ollama/llama.cpp setup. Needs an M5 Mac with 64GB+ RAM. JetBrains says it benchmarks on par with Sonnet 4 for their coding-agent workload — their own comparison, not independently verified.

A concrete local-fallback data point if we ever want RealGenie or ReBuddy agents to keep working offline or under a sensitivity threshold.

Worth knowing

114 pts · HN

LLMs could control the machine that runs them

Essay on how a malicious or compromised LLM could exploit its own inference engine to break out to the host. Concrete example: CVE-2025-9141, an arbitrary-code-execution bug in vLLM's XML tool parser for Qwen3 Coder that piped tool-call arguments straight into eval().

If we ever self-host inference for agent tool-calling, the tool parser is an attack surface we don't normally think about — worth a read before wiring any local inference engine to agent tool calls.
