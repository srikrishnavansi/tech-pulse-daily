Repo of the day

769 ★ new — public since Aug 17, already on the breakout list

browser-use/macos-harness

One Python process that hands an LLM full control of a Mac: accessibility tree, AppleScript, screenshots or raw coordinates, plus the browser, files and shell. No framework, no recipes — the agent writes what's missing mid-task. Install with uv, register the skill it prints, run `macos-harness doctor`.

Why it matters: Closer to the harness philosophy worth stealing for your own tool layer than most frameworks: thin surface, real OS primitives, the model fills gaps instead of a framework pre-deciding them. The maintainers already call out prompt injection as a live risk once a harness has both a click primitive and a shell — worth reading even if you don't run it.

Newest tools

launch

deepseek-ai/deepseek-harness

MIT-licensed agent harness where every capability — tools, UI surfaces, even the desktop shell — ships as an installable plugin (`npx @deepseek-ai/dsh plugin add ...`). Went public Aug 13, passed 10K stars in under two hours, sits at ~126K stars with a community plugin index already past 1,080 plugins.

The plugin manifest format is worth a skim purely for the design even before installing anything — but the ecosystem is two weeks old and mostly unaudited third-party code, so treat any given plugin the way you'd treat an unreviewed dependency.

plugin

ysr666/dsh-vision-router

Gives text-only DeepSeek Harness agents a keyless vision chain plus pixel-level tools (Q&A, grounding, crop, pixel-diff, OCR, SVG trace, cutout, screenshots), wired up so looking at an image is an ordinary tool call. One-command install, no Python.

The routing pattern — pixels stay on a vision model, reasoning stays on the text model, glued by tool-calling — is a clean template for adding a vision fallback to a text-only agent step without moving the whole pipeline to a multimodal model.

release

ggml-org/llama.cpp v0.3.0

Adds dots3-note multimodal support with a new DSA-ISWA KV cache, MTP (multi-token prediction) for GLM-4.5-Air, tensor-split mode and multi-sequence rollback fixes for DeepSeek 4, and tabbed chat navigation in the bundled web UI.

The DeepSeek 4 tensor-split fix and GLM-4.5-Air MTP support are the two changes worth pulling if you're using local models on a fallback path.

Worth knowing

129 pts · HN

LatticeDB: an embedded graph database aimed at RAG

Single-file, embedded property-graph database combining vector similarity, full-text search and graph traversal in one Cypher query. The maintainer reports sub-microsecond cached lookups and 99-100% recall@10 at 1M vectors.

That's the maintainer's own benchmark, not independently verified — but the pitch of one file, one query language, three retrieval modes is close to the shape of a debuggable, per-agent memory store rather than bolting a vector DB onto Postgres.

Skip this one

dataelement/dsh-desktop

2,536 stars in days, riding the DeepSeek Harness wave — pitched as a full desktop shell (windows, tray, terminal, updates, plugin marketplace) for the ecosystem.

Every account discussing it describes the plugin architecture of the desktop chrome or the underlying dsh harness itself — none report a completed install, a running session, or a crash. No install logs, no 'it works,' nothing to check the star count against yet.

X coverage relied on the pre-run viral sweep; a curated-account pass and a targeted question about dsh-desktop both came back thin or empty, which is reflected above rather than padded.
