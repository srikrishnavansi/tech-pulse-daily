Anthropic's own reference blueprint for shopping and merchant agents: a customer-facing Shopping Agent and a back-office Merchant Agent, both built on a shared commerce-common package for config, memory, skills, grounding and safety. Same coding model, 9 harnesses, 17x cost spread

FrontierHarness Eval ran one model through 9 agent harnesses across 12 configurations on identical software-engineering tasks. Pass rates clustered within 17 points of each other, but median cost per completed task ranged from $1.05 to $18.34. Codex was the safe default at $3.47/pass; DeepSeek Harness's four presets alone varied 6.6 points of pass rate and 1.4x in cost on the same model and runtime.

Direct evidence that harness plumbing, not model choice, drives a lot of agent cost variance — worth running RealGenie's own tasks through a comparison like this before assuming a model swap saves money.

188pts · HN

Claude Fable 5.1 agent swarm builds an explorable 3D city block

PhiloLabs' fable51-worlds reconstructs real places — first up, Union Square in San Francisco, with 129 identified storefronts, working traffic lights and two explorable interiors — as plain Three.js apps. The pipeline is autonomous Claude Fable 5.1 agents doing reconnaissance from open data and reference imagery, offline asset generation via Blender scripts, runtime assembly, and QA via Playwright diffing rendered frames against real photographs.

The recon-generate-assemble-QA pipeline, especially using Playwright to visually diff agent output against ground truth, is a pattern worth stealing for any RealGenie agent whose output can be checked against a real-world reference.
