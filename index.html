achimala/dream-loop

A Claude-Code-style agent skill for generating 3D visuals in Blender: one pass drives Blender's Python API plus an image model for a reference, then a second subagent acts as critic — renders the result, compares it against the reference, and kicks back specific fixes until the render passes. The loop is the point, not the 3D output.

Why it matters: This is the pattern worth stealing for our own skills: a critic subagent that grades output against a reference and forces a retry instead of trusting the first pass. Applicable anywhere in the RealGenie skill set where 'looks right' needs a checker, not just a generator.

Cognition SWE-2

Cognition's new coding model, built by taking Moonshot's open-weight Kimi K3 and running their own large-scale RL on top, including a method that trains three effort levels (medium/high/max) in a single run. Scores 50.0% on FrontierCode 1.1 Main — within a point of Fable 5.1 — at roughly 64% lower cost, per Cognition's own numbers.

A cheaper coding-agent backbone worth a bakeoff against whatever RealGenie's agents call today, but treat the benchmark as a vendor claim until we run our own eval.

DeepSeek V4.1 Flash

New open-weight model from DeepSeek: multimodal MoE with a 552B backbone, up to 1M-token context, native visual understanding. DeepSeek says it now beats V4 Pro on quality, cost and speed, and is routing all V4 Pro API traffic to Flash starting Sept 14.

Open weights, a big context window, and a real price cut — worth testing as a self-hosted option anywhere RealGenie or ReBuddy is currently paying for a bigger model.

Skip this one

FareedKhan-dev/kimi-k3-in-c

7,493 stars this week for '2.78-trillion-parameter Kimi K3 running inference on a single CPU in 8.24GB of RAM, portable C99, no BLAS, no GPU.'

The RAM number is real for what it measures — it's an MoE with 896 experts, only 16 active per token, so the always-resident set is small and the rest stream from disk. But decode runs at roughly 11 seconds per token, and peak memory once cached experts are counted hits 127.9GB, not 8.24GB. It's a legitimate proof that MoE streaming works on a CPU, not something you'd run for actual inference.
