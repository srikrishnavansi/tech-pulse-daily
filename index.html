Repo of the day

★ published today

huggingface/funes

Indexes your past agent sessions across Claude Code, Codex, pi and Hermes into durable, searchable memory. Publish it as a dataset on the Hub and any machine, teammate or agent can pull from it: ask a question, and Funes recalls the relevant past sessions, hands them to a coding agent, and returns one grounded answer naming the sessions it drew from. Secrets are redacted at index time, with a separate always-on gate that refuses to publish any chunk still holding one.

Why it matters: This is close to the shared memory layer the team keeps talking about building for RealGenie's 13 agents — session history that outlives the terminal it ran in, retrievable by any agent later, instead of context that dies when the window closes. Worth prototyping against our own Claude Code sessions before building this in-house.

Newest tools

open weights

K2 Horizon (IFM)

Six models, 0.9B to 375B-A23B, all Apache 2.0 with full weights, training code, training data, recipes and checkpoints — not just weights. The 0.9B/3.7B/7B target on-device (phones, wearables); 36B-A4B is a sparse MoE (~4B active) with 512K context, and GGUFs are already showing up for it.

This is the kind of open release a local fallback can actually be built on. Caveat: it launched today, 'frontier performance' is IFM's own benchmark, and nobody has published an independent run yet.

MCP

totec448-spec/chat-on-steroids

MCP bridge giving ChatGPT a durable local session via a Chrome extension: exposes at most seven tools to the model at once, revokes permissions instantly mid-conversation, logs every tool call locally, and drives a chat toward a stated goal through a Compact & Resume cycle that survives a context reset.

The tool-cap-of-seven and instant-revoke pattern is a tighter permission model than most hand-rolled MCP servers ship with, and Compact & Resume is the exact context-compaction problem the RealGenie agents hit, solved as a first-class feature instead of a workaround.

Codex CLI ships a plugin marketplace and vim undo/redo

The plugin CLI can now list, install and remove plugins from remote marketplaces. Vim mode gets undo/redo that preserves drafts, pasted content and attachments; TUI history shows full patches and background-terminal input; tui.auto_recap can be disabled while keeping manual /recap.

Anyone driving Codex directly should look at the plugin marketplace CLI before hand-rolling another install script.

44.9% vs 21.1% baseline · IFStruct

100 GRPO steps take a 350M model past 4B+ models on structured output

TRL writeup: GRPO fine-tuning moves a 350M model from 21.10% to 44.90% on IFStruct (valid JSON/YAML against a target schema) — ahead of Qwen3.5-4B (36.25%) and granite-4.0-h-tiny (38.75%).

Structured-output and tool-call reliability is exactly what breaks agent pipelines in production. This is a small, repeatable recipe for hardening a cheap model instead of reaching for a bigger one.

717★ · new

A reverse-engineering agent that checks its own claims against the binary

Grounds AI-assisted reverse engineering in deterministic tools — every claim the model makes about a binary gets checked against the actual bytes rather than taken on faith.

Same failure mode as an agent hallucinating a file's contents or a test result. Worth reading for the verification pattern even without a reversing use case.

260M / 800M params

Small multilingual encoder handles text and images in one pass

A single bidirectional transformer processes text tokens and raw image patches together, no separate vision tower, trained with a masked discrete-diffusion objective. Fine-tuned for visual document retrieval (ColPali-style); the 260M model encodes about 51 page-images/sec on an L40S.

Relevant if the memory layer ever needs to index floor plans, listing photos or scanned documents rather than text alone — a smaller retrieval encoder than the usual VLM route.
