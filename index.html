CopilotKit/OpenBot

Open-source "AI coworker" workspace: each bot gets its own governed browser, its own files, and only the tools you explicitly grant, with every action decided before it executes and logged after. It speaks AG-UI, so it wraps agents built with LangGraph, CrewAI, Google ADK, Mastra, Pydantic AI, or a hand-written harness — it's not tied to one framework. MIT-licensed, tagged v0.0.1, and openly alpha; CopilotKit's own team is telling people to expect rough edges and treat it as a test drive, not production.

Why it matters: The pre-execution approval plus post-execution log is the piece a lot of hand-rolled harnesses fake or skip — worth reading the architecture even if you never adopt the workspace itself, especially for anything that touches real RealGenie data.

guillaumemeyer/watermarks-remover

17,834 stars. Claims to strip AI provenance marks across vendors — invisible Unicode watermarks, statistical text rewrites, and C2PA/EXIF/XMP metadata from PNG/JPEG/SVG/PDF/DOCX/HTML/MD — positioned against Claude, Gemini/SynthID-class, OpenAI, and open-LLM sampling marks.

The X evidence for this is essentially the maintainer's own merged PRs and a DMCA takedown notice against a copycat repo — no independent post shows anyone running it against a real C2PA-marked file and confirming the mark is actually gone. Until someone outside the project verifies it works, the star count is attention, not proof. Worth naming plainly what it does, too: defeat AI-content provenance signals, not a neutral utility.
