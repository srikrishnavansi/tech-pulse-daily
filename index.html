CosmosMind-ai/RSI-Harness

A 'Genome' is a whole agent harness config — system prompt, tools, skills, MCP servers, runtime policies, memory, keybindings — collected into one versionable directory instead of scattered across settings.json, CLI flags and pasted prompts. `rsih :<name>` launches it; handing someone the directory reproduces your setup on their machine.

Why it matters: This is the exact problem of running Claude Code skills and MCP servers ad hoc across RealGenie's ~13 agents — one diffable, shareable config object instead of tribal knowledge. It's early: open issues show genome installs failing instead of no-oping and repeated installs overwriting backups, so treat it as a pattern to steal, not a dependency to adopt yet.

Pizza Bot (AWS)

A self-hosted desktop inbox for long-running agents, built on DeepAgents and LangGraph. Start or schedule a task and it surfaces later in an email-style UI: Unread for finished work, Action for runs paused waiting on your approval or answer. Multi-provider (Anthropic, Bedrock, Gemini, OpenAI, OpenRouter, local Ollama) and extensible via MCP servers and Agent Skills. Started as an internal Amazon tool (JoeBot) with 30+ contributors and 2,000 internal users before this open-source release.

It's the human-in-the-loop approval queue this team keeps hand-rolling for background agent runs — worth spiking against before building another one from scratch.

launch

Gemini 3.8 Live / Extended Thinking

Google's new live dialogue models, rolling out across the Gemini API, AI Studio, Gemini Enterprise and Workspace. Extended Thinking adds multi-step reasoning and narrates its thought process mid-task while still handling interruptions and language switches. Google's own numbers: #1 on Artificial Analysis' Speech-to-Speech Quality Index (82.6) and 68.6% on the τ-Voice agentic benchmark.

A voice model that reasons out loud mid-task is a real fit for property-AI phone/voice flows — worth a trial against whatever's wired into RealGenie today.

early access

TypeSafe AI — Jev

A 'System One Model' that skips string generation entirely: typed, calibrated probabilistic decisions out instead of tokens, trained with what TypeSafe calls Reinforcement Learning for Calibrated Decisions. Pitched as a frontier-intelligence function call that structurally can't hallucinate. Early access only; the 'two orders of magnitude faster' claim is TypeSafe's own benchmark, not independently verified.

If the claims hold up under real load, this is the shape of the fast, cheap router/classifier step inside a multi-agent pipeline where you don't want an LLM free-associating JSON.

Pentester got admin access to Baseten's GitHub from a public Docker image

Strix found a live GitHub PAT baked into a public Baseten Docker image via a build-time argument used to fetch private dependencies. The token was from a March 2023 build and still had admin access to product, deployment and CLI repos — including a customers directory — when tested in July 2026.

The same failure mode — a long-lived PAT passed as a build arg, never scrubbed from the image layer — is easy to reproduce in any Dockerized inference or agent-hosting pipeline. Worth an audit of build secrets on anything the team pushes to a registry.

Claude Code improves MCP disconnect handling

Latest release adds gateway hint headers, smoother remote-control session forking, and better recovery when an MCP server drops connection mid-session.

Touches the MCP servers this team maintains directly — worth upgrading before chasing a disconnect bug that may already be fixed.

Ollama tightens memory handling for local MLX models

Evicts prefix-cache snapshots and waits for freed memory before loading the next MLX model; raises the token repeat limit and now errors instead of silently returning incomplete output.

Relevant if anyone's running a local fallback model on Apple silicon — the silent-incomplete-output failure mode is now a hard error instead.
