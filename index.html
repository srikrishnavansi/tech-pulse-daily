Opus 5.5 ships, OpenAI answers in 90 minutes

Anthropic's Claude Opus 5.5 is now Claude Code's default model; about ninety minutes later OpenAI cut GPT-6 Sol and Luna to undercut it on price. X's practitioner take on any of this is missing today — all three research queries hit a credits wall — so what follows is GitHub, HN, and blogs only.

Repo of the day

1,170 ★ new this week, climbing fast

unreallabsai/unreal-agent

Go, MIT-licensed, async-first agent harness. Tool calls run independently of model turns instead of blocking a request-response cycle, so the model can kick off a long tool, keep working on something else, and consume the result when it lands. Drives models from OpenAI, Codex, OpenRouter, Fireworks and Ollama, and ships with its own benchmark runner. Unreal Labs claims up to 39% lower cost than Codex+Astra on Terminal-Bench 4.0 at comparable performance — that number is their own benchmark, not independently verified.

Why it matters: This is closer to how a 13-agent fleet like RealGenie actually needs to run tools than the synchronous request/response loop most harnesses default to. Worth reading the Session/LLM-turn/Tool abstractions even if we don't adopt it wholesale.

Newest tools

release

anthropics/claude-code v2.1.280

Claude Opus 5.5 is now the default Opus model in Claude Code — 1M context, $4/$20 per Mtok, $0.20/Mtok on cache reads. Also adds CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH to lift the 2,048-char cap on MCP tool/server descriptions, and fixes background sessions that couldn't run git, hooks or plugins when an env var contained a NUL byte.

Free default upgrade for every session here. The MCP description cap change is worth checking against our own MCP servers — it's an easy place to have been silently truncated.

launch

OpenAI: GPT-6 Sol & Luna

Launched roughly 90 minutes after Claude Opus 5.5, priced below it: Sol at $2/$10 per Mtok versus Opus 5.5's $4/$20, Luna at $0.10/$0.50. On the one benchmark both vendors report (AutomationBench), Opus 5.5 leads 40.0% to Sol's 33.2%.

If any RealGenie agent is cost-bound rather than quality-bound, Sol is now the cheaper thing to benchmark against — but the benchmark numbers are each vendor's own, not third-party.

release

unslothai/unsloth v0.1.814-beta

Local inference for Qwen-Image-2.1, plus custom Agent Skills that reuse straight from Claude Code's .agents folders, and reasoning blocks rendering at 60fps instead of 30fps.

The skill-reuse path is the interesting part — skills already written for Claude Code apparently drop into local Unsloth runs without a rewrite, worth confirming.

release

BerriAI/litellm v1.102.0

Streaming guardrails: post-call policy pipelines used to only see a finished response, now they run on the stream itself and can rewrite text and tool calls as tokens go out. Auto Router also now caps output at the selected tier model's limit by default instead of the caller's.

If RealGenie traffic goes through litellm, the auto-router default change is a silent behavior shift on upgrade — check max_tokens_from_tier_model before bumping the version.

262 pts · HN

Claude Opus 5.5's price/performance, measured independently

Artificial Analysis ran its own numbers on Opus 5.5 rather than repeating Anthropic's launch claims — $4/$20 per Mtok, 1M context, benchmarked against the current field.

Worth five minutes before anyone here recalculates cost projections off vendor slides alone.

64 pts · HN

Chinese open-weight models are lapping US ones

Nathan Lambert's read on the Artificial Analysis Intelligence Index: Z.ai's GLM-5.3 (45) and Moonshot's Kimi K3 (44) lead; the best open US models, Thinking Machines' Inkling (26) and Nvidia's Nemotron 3 Ultra (23), trail badly and update far less often.

If we ever want a local fallback model with a real story, GLM-5.3 and Kimi K3 are the ones worth test-driving, not the US open-weight names.

1,113 ★ · breakout

CopilotKit's OpenMuse: an agent with a visible computer

A personal agent that runs a persistent browser and an isolated Linux terminal as an 'agent computer' you can watch or take over mid-task, streaming everything over AG-UI events, with delegated background tasks and a follow-up queue instead of one blocking turn.

The pattern worth stealing is the visible, take-over-able work surface, not the email/finance vertical it ships wrapped in — useful if a RealGenie agent ever needs a human-inspectable long-running session.

llm 0.36

Simon Willison's llm CLI adds Anthropic and Jev plugins

llm-anthropic 0.29 and a new llm-typesafe 0.1a0 plugin landed alongside core llm 0.36, so the same CLI now scripts against both Claude and TypeSafe's Jev model.

Useful for a quick throwaway eval script comparing providers without wiring up separate SDKs.

OpenAI blog

GPT-6's prompt caching gets explicit breakpoints

Higher default cache hit rates, a 30-minute reuse window, diagnostics for cache misses, and explicit breakpoints for choosing where a cached prefix ends. GitHub reports over 50% fewer prompt tokens needing fresh processing across billions of Copilot requests.

Explicit cache breakpoints are the feature to compare against Anthropic's cache_control blocks next time we tune a long-context agent prompt for cost.

Skip this one

Jev — TypeSafe AI's "System One" model

A curated awesome-jev list hit 1,349 stars and a companion awesome-jev-tools hit 664, a benchmark called JevBench showed up on Show HN, and an HN post asked whether OpenAI can even fast-follow it — all in the week after a September 15 limited launch.

Nothing here you can actually run. TypeSafe hasn't published weights, architecture, or parameter count — Jev only runs on their own servers, rate-limited to 250k tok/s and 1,200 rpm, and the launch came bundled with a funding round rather than a paper or repro. The awesome-lists and JevBench are tooling built around a closed API, not open infrastructure.
