Newest tools

launch

DeepSeek V4.1 Flash

284B-parameter MoE (13B active) launched this week as the cheaper sibling to V4 Pro (1.6T total, 49B active). Independent third-party testing (Artificial Analysis, The New Stack) puts it about 1 point behind Pro on the Intelligence Index and close on SWE-bench Verified (~79% vs ~80.6%), while output tokens run roughly 3x cheaper.

A near-Pro coding model at a third of the cost is worth a real bake-off against whatever's currently routing coding-agent traffic — that cost delta compounds fast across 13 RealGenie agents.

launch

Desert Ant Labs

New on-device AI lab launched with 18 audio/vision/text models and SDKs for Swift, Kotlin and JS. Its Voz model transcribes 10 minutes of audio in 2 seconds on an iPhone — 4.7x faster than Whisper — with word-level timestamps; Clear does on-device speech enhancement, running on the Neural Engine natively or as WASM in-browser.

No per-call cost and no network hop for audio — relevant anywhere ReBuddy or RealGenie touch voice input and don't need it to leave the device.

launch

geiger

Show HN launch: one read-only CLI command that inventories every AI agent, MCP server, plugin and AI extension running on a machine — what's installed and what it can reach.

Straightforward way to audit what MCP servers and skills are actually live across a multi-agent deployment before assuming the permission model matches reality.

v2.1.266 · release

Claude Code fixes a gateway-auth regression

Patches a 2.1.265 regression where the undocumented CLAUDE_CODE_USE_GATEWAY env var forced Cloud-gateway sign-in on its own, breaking setups that combined it with an API key, apiKeyHelper, or custom auth headers.

If your harness sets that var alongside a proxy or gateway config, update — no config change needed once you're on 2.1.266.
