89 pts · HN

Dream-RSI: Recursive Self-Improvement through Evolving Worlds

Instead of testing every new exploration policy with fresh, expensive model rollouts, Dream-RSI replays completed discovery histories as offline environments and scores candidate policies against that replay tree. Paper and code are both public.

A concrete technique for cutting the cost of 'try a new strategy, see if it helps' in any self-improving agent loop — relevant if you're building memory or self-tuning into the RealGenie agent stack without burning live rollouts on every experiment.

122 pts · HN

Intelligence per Watt: Measuring Intelligence Efficiency of Local AI

Empirical study across 20+ local models, 8 accelerators and 1M real queries proposing accuracy-per-watt as the metric for local inference. Local models already handle 88.7% of everyday chat/reasoning queries; local efficiency improved 5.3x from 2023-2025, but local accelerators still run about 1.4x less efficient than the same models in the cloud.

Hard numbers for the 'can we run this locally' conversation — useful if you're weighing on-device inference for RealGenie or ReBuddy against cloud calls.

372 pts · HN

Why I'm still bearish on LLMs after Navier-Stokes

Argues autonomous-agent progress is bottlenecked by verification, not model intelligence: output needs either a rigorous spec plus a domain-and-spec expert to check it, or human review, which doesn't scale and gets gamed. Navier-Stokes is held up as the rare case where a real spec and verifier existed for free.

A useful gut-check against over-promising autonomy in the RealGenie/ReBuddy agents — for each one, worth naming the actual verifier before shipping more autonomy.
