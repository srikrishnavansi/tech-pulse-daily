GPT-6 Astra (OpenAI)

New flagship model: 1.05M-token context, 128K max output, text+image input, $10/$50 per M input/output tokens via API. Rolling out to Enterprise, then Plus/Pro/Business, the API, and AWS. Codex CLI (rust-v0.153.1) already added it as a config-only option — not in the in-session model picker yet, reachable by setting reasoning_effort to high or xhigh.

You can point Codex at it today without waiting for the picker. Treat the headline numbers (98% FrontierMath Tier 4, 99.9% ARC-AGI-3, 100% ExploitBench) as OpenAI's own benchmarks — nobody outside OpenAI has verified them yet, and our X pull for real developer reports came back empty this run.

New /diff fullscreen panel showing uncommitted changes live as Claude edits, /cost now explains likely causes of prompt-cache misses (tool defs, system prompt changes, TTL expiry), /reload-plugins added to headless sessions, plus fixes to Bash permission-rule parsing (parentheses were being dropped) and subagent resume notifications routing to the wrong conversation.

Skip this one

DietrichGebert/ponytail

124,963 stars on GitHub as of this run, ~44K of those in its first 9 days. Billed as making an agent "think like the laziest senior dev in the room," with a headline claim of 80-94% less code generated.

A contributor checked the benchmark and found the baseline was flawed; the maintainer reran it as a real agentic run and the number dropped to 54%. Scott Logic's CTO dug into the repo itself and found the actual substance is a roughly 100-line markdown file restating YAGNI, wrapped in a large pile of per-plugin boilerplate (Cursor, Windsurf, Cline, Copilot, etc.). Star count is not a substitute for reading the rules file yourself.
