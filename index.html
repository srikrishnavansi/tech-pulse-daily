Newest tools

launch

cinderline/northcinder

Self-hosted MCP server that has an agent compare products against a brief and return a ranked shortlist with reasons. Deterministic ranking (seller payment never affects position), a signed purchase mandate required before checkout, and a local audit trail. No hosted service, no telemetry — runs on your machine.

A clean reference for the parts of MCP server design that are easy to skip: an explicit approval gate before an agent can act, and an audit trail you actually control.

launch

PicoMQ

Durable, real-time streams over HTTP built directly on S3-compatible object storage — no broker to run. One stream per use case instead of one shared topic, each independently addressable and scaling from idle to high throughput.

Worth a look next time an agent pipeline needs a queue between steps and standing up Kafka or Redis feels like overkill.
