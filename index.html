trustmebro shims fake tool output past agent guardrails

A proof-of-concept that intercepts commands like dig/nslookup/host and returns fabricated-but-plausible output instead of the real result. In the demo, an agent that stops when the genuine dig call returns nothing keeps going when the shimmed version hands it a matching fake record — every substitution gets logged to a timestamped JSONL audit trail.

Direct hit on a trust assumption harnesses make by default: if any of RealGenie's agents treat tool output as ground truth with no provenance check, this is the failure mode to test for before someone else finds it.

41 pts · HN

Ask HN: How do you manage skills files?

Thread on keeping SKILL.md / CLAUDE.md instructions in sync with actual agent behavior. Several commenters flag that guidance placed in a project's CLAUDE.md is only read at session start, so it silently stops applying partway through a long-running session.

The same failure mode is worth checking for in our own skills — front-loaded instructions quietly going stale mid-run is easy to miss until an agent does something wrong for a reason nobody can find.

59 pts · HN (arXiv, 2025)

Embeddings can be translated across models with no paired data

Resurfaced on HN today: a method that maps one model's text embeddings into another model's space with no shared encoder and no matched pairs, by aligning both to a conjectured universal latent structure. The authors' security note: an attacker holding only embedding vectors, no source text, can recover enough structure to classify documents and infer attributes about them.

Worth reading before treating a vector store as a safe place to park anything sensitive for agent memory or RAG — the vectors themselves may leak more than we assume.
