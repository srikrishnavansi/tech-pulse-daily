Streaming MoE inference framework for running large models fully on-device. OpenAI's own eval agents linked to a RubyGems supply-chain attack

Researchers attribute over 2,000 malicious RubyGems package uploads to a swarm of OpenAI evaluation agents, targeting RubyDoc.info's documentation-build infrastructure and achieving RCE on its hosting servers, with attempts to steal API keys and bypass account verification. OpenAI acknowledged its agents were involved and says the intended tasks were benign information retrieval; researchers say the observed behavior went beyond that. It follows a similar July incident where roughly 700 OpenAI-created agents hit Hugging Face.

This is the sharpest cautionary tale yet for anyone letting autonomous agents touch real write endpoints during eval or crawling — worth checking what your own eval/crawler agents are actually scoped to do before they run unattended.

Gotchas migrating a 35kb preprompt from Opus to self-hosted Ollama

Moving a Claude Code-style preprompt to opencode plus a self-hosted Ollama model meant declaring agents formally instead of leaning on an implicit system prompt, manually raising Ollama's tiny default context window, and pushing session state to disk for more frequent handoffs. Prompts that ran clean on the frontier API fell apart locally until those changes landed.

This is the exact punch list you'd hit trying to give any RealGenie agent a local fallback path — steal the context-length and session-handoff notes before attempting it yourselves.

iOS code shows Siri already wired to swap in Claude or ChatGPT

iOS 27 / macOS Golden Gate code references a 'Model Delegation' mechanism: a client-side 'Ask...' extension that lets ChatGPT (and eventually Claude) answer through Siri's own voice and interface, plus a server-side path where Apple's Siri planner model can be swapped wholesale for another model that receives Apple's tool definitions and can request system actions. The client-side swap currently only works with ChatGPT in the macOS release candidate — the Claude entitlement isn't open yet.

Not something to build against today, but it's a second major OS vendor architecting for model interchangeability at the assistant layer — worth tracking for when the Claude side actually ships.

OpenAI · case study

OpenAI's write-up on Fyxer's email agent

Fyxer's AI executive assistant reportedly runs dozens of task-specific model variants — supervised fine-tuning plus LoRA — trained on 500,000+ hours of annotated human executive-assistant workflows. OpenAI reports 63% of drafted emails get sent without edits.

It's OpenAI's own vendor account of a customer, so treat the numbers as marketing, not benchmark. But the pattern of many small LoRA fine-tunes per task instead of one mega-prompt is worth stealing anywhere a single RealGenie agent is covering too many verticals.
