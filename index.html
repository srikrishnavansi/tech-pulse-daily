All three X research queries hit the team's API credit limit today, so there's no verified trending-post data to lead with. Newest tools

launch

Jev (TypeSafe AI)

A new model shape TypeSafe AI calls a 'System One' model — Simon Willison and Maggie Appleton prefer 'decision model.' You send it a document plus as many yes/no, rating, or classification questions as fit the context window; it evaluates them in parallel and returns floating-point probabilistic answers with confidence scores instead of generated text. Priced at $0.042/M input tokens, output is free.

This is the shape of thing you'd put in front of routing/triage/label decisions across the RealGenie agents instead of burning a full chat completion on a yes/no. TypeSafe's own numbers claim 193x faster and 445x cheaper than a comparable LLM call — that's their benchmark, not an independent one, so test it against your own classification workload before trusting the multiplier.

launch

MiMo-V2.6-Pro (Xiaomi)

Open-weights flagship: 1.02T-parameter MoE with 42B active, 1M-token context, multimodal input (text/image/speech/video), MIT-licensed on Hugging Face. Debuted as the top-scoring model on Artificial Analysis's open-weights Intelligence Index (46, field median 18) at $0.13 per index task.

A legitimate self-hostable option if you're evaluating a local fallback model — the ranking comes from a third party (Artificial Analysis), not Xiaomi's own marketing, which is rarer and more worth trusting than most 'best open model' claims.

launch

Drop (droprun.sh)

A rootless Linux sandbox: runs a program in its own user/mount/network/IPC/cgroup namespaces without root, with an opt-in gVisor layer for a harder isolation boundary. Uses your existing distro instead of a container image, configured via a shared TOML base config.

A lighter primitive than standing up Docker/Podman just to cage what an agent's shell tool can touch on a dev box — worth a look for sandboxing tool calls.

launch

Claude Opus 5.5

Anthropic's new flagship, tested pre-release by METR and Frontier Design. Anthropic says it scores best-yet on their internal behavioral/alignment audit and cites an early tester finishing a 680,000-line code migration in under a day.

The migration anecdote is Anthropic's own, not a benchmark you can reproduce — worth running your heaviest RealGenie or ReBuddy refactor through it yourself before taking the number at face value.

Worth knowing

vLLM v0.30.0

vLLM's Fast Start cuts cold engine init 3x

A persistent per-GPU daemon now holds post-quantized, tensor-parallel-sharded weights resident in GPU memory; engines started with --load-format ipc_cache map them over CUDA IPC instead of reading a checkpoint off disk. On an H200, engine init dropped from 28.9s to 8.2s and CUDA graph capture from 12s to 2s.

Cuts real pain out of autoscaling self-hosted inference — relevant if any RealGenie or ReBuddy workload sits behind vLLM.

Unsloth v0.1.812-beta

Unsloth adds custom Agent Skills alongside Qwen-Image-2.1

New release brings Qwen-Image-2.1 support, custom Agent Skills for automating fine-tuning workflows, and roughly 2x faster reasoning-block training.

Another sign 'Skills' as a packaging convention is spreading past Claude Code — worth a look if you want the same shape across your own fine-tuning tooling.

Meta's privileged Muse assistant had an auth-hijack bug

Security researcher Patrick Wardle published a PoC (not-a-mused) showing an unprivileged local process on macOS can flip a hidden Muse preference, redirect its transcription endpoint, and hijack the auth token controlling a user's account — undermining macOS's own permission model.

The failure mode is worth checking for in anything you ship: a privileged assistant plus a hijackable local config file is exactly the shape of gap to audit in your own tool-using agents.

A blog post turns gzip into a language model

Exploits the equivalence between compression and prediction: primes gzip's window with a corpus, then beam-searches candidate continuations scored by compressed length — no neural net, no training. Code is on GitHub (nathanrs/gzipt).

Nothing to ship, but a clean intuition-builder for why perplexity and compression ratio are the same number in different clothes.
