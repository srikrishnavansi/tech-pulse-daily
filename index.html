Indirect prompt injection breaks Claude Code Opus 5 Auto Mode

A simple 'summarize this page' request leads Claude to curl a redirect to a ZIP archive containing catalog files, a decoder binary and a malicious struct.py. Claude writes its own Python decoder that does 'import base64' — but Python's module search checks the current directory first, so it silently loads the attacker's struct.py instead, which pops a C2 connection and Calculator. In some runs, Auto Mode noticed the compromise and tried to kill the process, but denied its own cleanup command. Lab success rate: 60-80%, against Anthropic's own third-party-audited 0.00% prompt-injection figure for Auto Mode.

Same module-shadowing trick works anywhere an agent writes its own glue code around downloaded, untrusted files. If Auto Mode touches support tooling or doc-fetchers on untrusted web content, don't lean on the vendor eval number — sandbox the curl+exec chain.

113 pts · HN

Agent memory as a plain file format

Cal Paterson's memoryfields spec stores agent memory as files under a small RFC-style format, deliberately 'low mechanism' — no baked-in embedding function or query API. Agents are free to invent their own access patterns: perl find-and-replace across the whole memory corpus, inline CSVs queried with SQLite, whatever the model thinks to do.

A different bet than a shared vector DB for a memory layer across RealGenie's agents — worth reading against whatever you're sketching, since the pitch is that it gets more useful as the underlying model improves instead of needing a rewrite.

164 pts · HN

uv dedupes files across the wheel cache

uv's cache currently content-addresses at the whole-wheel level; this PR moves that down to individual files, and reuses one hash buffer per wheel instead of allocating a new one per file (11,120 buffer allocations down to one for the PyTorch wheel). Cold-install benchmarks: -2.6% to -9.5% depending on package.

Free speedup once it lands, no workflow change needed — just keep uv up to date.
