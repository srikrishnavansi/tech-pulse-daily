104 pts · HN

Claude Code leaks session URLs into commit messages by default

Every commit and PR Claude Code writes gets a claude.ai/code/session_... URL appended, with no opt-in prompt or onboarding warning. A dedicated attribution.sessionUrl setting (added in v2.1.183) can turn it off for web/Remote Control sessions.

Worth checking our own Claude Code settings — this leaks internal session links into commit history, public or otherwise, until it's disabled.

339 pts · HN

AI crawlers are now almost all of git.kernel.org's traffic

Konstantin Ryabitsev's writeup: legitimate human traffic is roughly 2% of requests to git.kernel.org; the rest is scraper bots, increasingly from millions of rotating residential/mobile IPs making 4-5 requests each, which defeats IP-based blocking. 14-16 of 90 cores stay busy just rendering commits for scrapers, and an Anubis proof-of-work challenge now bounces 66% of requests.

If we ever expose git, docs, or API surfaces publicly for RealGenie or ReBuddy, this is the traffic shape to plan for — proof-of-work challenges over IP blocklists.
