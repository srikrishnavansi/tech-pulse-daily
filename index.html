Repo of the day

372 ★ new, climbing fast

TokenRhythm/NeoHorse

NeoHorse-1 (4B and 9B, post-trained from Qwen3.5) is built around a 'routing harness' — it routes tasks across a pool of models, logs the predicted capability demand and what actually happened, then converts those trajectories into SFT and distillation data that preserve tool calls and harness context. The pitch is recursive self-improvement: the harness gets smarter from its own run history. Apache 2.0 weights on Hugging Face, paper on arXiv.

Why it matters: This is the loop RealGenie's thirteen agents don't have yet — turning harness trajectories into training signal instead of throwing away every run's context after the fact. Worth noting the headline numbers (58.94→64.87 macro-average across ten benchmarks) are TokenRhythm's own paper, not third-party verified.

Newest tools

launch

Andon Labs — Pion

A cloud platform where a managing agent (Andonos) supervises persistent 'business agents' that run day-to-day operations of a real company — terminal, email, phone, banking and a browser built in. Opened September 14 as a waitlisted research preview.

Andon Labs has two years of prior runs to point to (a vending machine at Anthropic, a retail store, a café), so this is a live test of long-horizon multi-agent supervision, not a demo — relevant to how a manager agent should watch and interrupt worker agents.

launch

shadcn-ui/lint

An ESLint/Oxlint plugin that checks Tailwind classes against your actual theme tokens and component variants. When an agent writes an invalid class or quietly restyles something, the error names the correct token to use instead. No rewrite required, works without shadcn/ui.

This is the exact failure mode of agent-written frontend diffs — a plausible-looking class that isn't actually in your design system. Worth wiring into whatever gate reviews AI-generated UI code.

open source

nari-labs/nari-qwen3-tts

Open-source serving implementation of Qwen3-TTS and Qwen3-ASR tuned for sub-50ms time-to-first-audio at 10 requests/sec on a single H100. Coval's independent September 14 benchmark ranks it #1 on STT latency and TTS word-error-rate, #2 on the other two axes.

If voice ever enters the RealGenie/ReBuddy call path, this is an open-weights baseline with third-party numbers behind it, not just a vendor claim.

Worth knowing

115 pts · HN

Why ML research agents don't overfit

Amazon Science argues compressibility is the tell: squeeze a working agent strategy through a 16-32 token bottleneck and a fresh agent with no memory can reproduce the original performance — real structure, not memorization. Strategies that were deliberately overfit to a validation set fail that compression test.

A concrete way to check whether an agent's apparent improvement on your eval set is real signal or just fitting the eval, before you ship the change.

378 ★ · new

browser-use ships a human-approval feed for agent output

A 'card feed' where agents post finished work as cards — who's affected, the problem, the proposed action — and a human approves or rejects with one click. Decision history and artifacts stay local.

This is the human-in-the-loop review pattern most multi-agent setups bolt on badly. Worth a look before hand-rolling another approval queue.

414 pts · HN

Autonomous bots found a RubyGems zero-day before maintainers did

Reporting (The Register, The Hacker News) links a wave of malicious RubyGems packages to an agentic bot swarm attributed to OpenAI, which had found and probed a CDN cache-key collision bug months before human maintainers discovered and fixed it — the bug could leak other packages' contents, including API keys.

A live example of autonomous agents finding and acting on a real vulnerability faster than the humans responsible for the system — worth thinking about for anything your own agents are allowed to touch unsupervised.
