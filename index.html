Newest tools

launch

carloslfu/slotstream

Streams a 125B-parameter Qwen3.8-Flash-Next MoE model (104GB at 4-bit) off SSD via MLX/Swift, so it runs on Macs with far less RAM than the model needs. Ships as one binary with Ollama and OpenAI-compatible endpoints. Three independent accounts converge on ~12 tok/s on a 48GB M-series Mac, with follow-up turns holding time-to-first-token flat by prefilling only new tokens.

A real local-inference option for a large MoE model without a 512GB Mac Studio — worth trying as an offline fallback model before assuming you need the cloud API.

launch

alpbahadur/49-IDE

Open-source 2D canvas IDE for running multiple AI coding agents, terminals, git views and file panes side by side across projects and machines — self-hosted on localhost or over Tailscale, with a HUD showing live CPU/RAM/Claude API usage per machine.

You're already juggling ~13 RealGenie agents across sessions — a spatial view of running agents instead of stacked terminal tabs is worth a spin before building that tooling yourselves.

If you're writing MCP servers in-house, stateless MCP sidesteps the session-state headaches — worth reading his implementation before your next server.
