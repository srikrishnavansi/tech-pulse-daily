Repo of the day

vercel-labs/eve-software-factory-template

Vercel's reference 'software factory': label a GitHub issue or delegate a Linear ticket, and the Foreman orchestrator runs it through four stations — a classifier triages, an analyst plans against a live repo checkout, an implementer writes code and runs your own checks in a sandbox, and a reviewer on a different model vendor grades the diff against the plan before opening a PR. If checks fail on its own PR it diagnoses and retries twice, then stops for a human.

Why it matters: This is close to the pipeline RealGenie's 13 agents already approximate by hand. The cross-vendor reviewer stage and the stop-after-two-failures rule are cheap guardrails worth lifting straight into your own harness.

Turns a reference photo into a Three.js scene as plain, editable TypeScript, a scene graph of primitives (rounded boxes, spheres, cylinders, extrusions) instead of an opaque GLB import. 1.5.1, shipped in the last day, treats an intermediate GLB from Meshy or Tripo strictly as a reference to rebuild from, not the deliverable.

wang2122/sprix-sage-router

Research-grade router for A2A agent networks that picks SELF / COLLABORATE / HANDOFF per task from live state, then assigns task-DAG roles and schedules dependencies under budget and deadline constraints.

Most agent routers use a static role table. This one treats routing as a per-task decision, closer to what you'd want if agents in a system like RealGenie ever need to renegotiate who owns a task mid-run.
