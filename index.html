Opus 5.5 and GPT-6 spark a price war

Anthropic shipped Claude Opus 5.5 on 2026-09-22 and OpenAI answered within the hour with GPT-6 Sol and Luna, cutting prices hard on both sides. Separately, TypeSafe AI's Jev launched a sub-second 'typed decision' model built for exactly the routing and classification calls multi-agent systems make constantly.

Repo of the day

kerpopule/hermes-jev-skills

A skill/memory/compaction layer for Hermes-family agents that uses TypeSafe AI's Jev model to make the small, frequent decisions — model routing, context compaction, which skill to invoke, computer/browser-use steps — without a full LLM call for each one.

Why it matters: Close to what RealGenie's 13 agents do constantly: pick a skill, decide whether to compact context, choose the next tool. Worth a look before building another routing layer around a full model call.

Claude Opus 5.5 / GPT-6 Sol & Luna

Anthropic shipped Opus 5.5 at $4/$20 per M tokens, with cached input reads cut 60% to $0.20/M. OpenAI answered within the hour, pricing GPT-6 Luna at $0.10/$0.50 per M — roughly a tenth of current Haiku 4.5.

If RealGenie or ReBuddy lean on prompt caching across the agent fleet, the Opus 5.5 cache-read price alone changes per-run cost. Worth rerunning the cost model before the next planning cycle.

launch

Jev (TypeSafe AI)

A 'System One' model that skips text generation: feed it unstructured state and it returns a typed, calibrated-probability decision (a class, a score, a yes/no) in one pass, at roughly 0.4s per call per TypeSafe's own numbers.

This is the shape of decision orchestration layers usually fake today by asking a full LLM for JSON. If it holds up under load, it's a cheaper, faster stand-in for routing, guardrail, and classification steps inside a multi-agent harness.

launch

Strands Harness

AWS's Strands Agents project shipped a pre-assembled agent harness with benchmarked defaults for system prompt, tools, memory, sessions, and context management — claims 28% lower token cost, model-agnostic across Bedrock, Anthropic, OpenAI, Google, and Ollama.

Directly comparable to the harness you hand-roll for RealGenie — worth diffing their context-management defaults (tool-result truncation, summarization at 85% context) against your own.
