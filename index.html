Newest tools

launch

Ordewell

Turns one goal into an ordered plan of coding-agent tasks, each with its own runner (Claude Code, Codex, or OpenCode), model, and thinking effort, then drives execution and verification from a terminal UI. A task counts as done only when its own completion marker shows up in the runner's output — the agent doesn't grade its own work.

Routing subtasks to whichever runner/model actually fits is a problem a 13-agent RealGenie setup runs into constantly. Apache-2.0, free, and the completion-marker verification pattern is worth stealing even if you don't adopt the whole tool.

launch

Panel

A local, dockable-pane research workspace (chat, files, PDFs, Jupyter notebooks) where the agent can build its own custom panes on request — a protein viewer, a SQLite browser, whatever the task calls for — instead of being boxed into a fixed UI.

Useful reference if you're building internal tooling for agents to inspect their own state or outputs; letting the agent construct its own UI surface on demand is a pattern worth watching.

Worth knowing

v1.101.0 release

LiteLLM adds a heuristic router and semantic MCP tool search

New release routes requests by estimated difficulty (with a circuit breaker if the classifier itself fails), adds semantic search over MCP tools so a gateway fronting more tools than fit in one prompt can still pick correctly, and splits Prometheus metrics into their own process with per-key/per-team rate-limit gauges.

Semantic MCP tool search matters the moment you're running more MCP servers than you can list in a system prompt — worth checking against whatever gateway sits in front of RealGenie or ReBuddy's agents.

v0.4.1 release

llama.cpp adds Maple 20B-A1B, Tencent Hy4, and Spark2.5 support

New release adds a ternary MoE architecture (Maple 20B-A1B), Tencent's Hy4 and Spark2.5 preview architectures, replaces the --mmap/--mlock/--direct-io flags with a single --load-mode, and adds structured JSONL logging.

If you're evaluating small local models for anything that shouldn't leave the building, the ternary MoE support is the one to try first for memory footprint.

IBM Research

A number for how often agents ace a task once but flake on the retry

IBM's ALTK-Evolve work introduces Scenario Goal Completion (SGC), a metric that only counts a task as passing if the agent succeeds on every variant, not just once. Distilling guidelines from the agent's own past trajectories and injecting them back at inference time — no weight updates, no human annotation — lifted SGC by +8.9 points overall and +14.2 on the hardest tasks. Code is open at github.com/AgentToolkit/altk-evolve.

This is the memory-and-self-improvement problem stated in concrete numbers instead of vibes — relevant if you're thinking about how RealGenie's agents should learn from their own trace history instead of starting cold every session.
