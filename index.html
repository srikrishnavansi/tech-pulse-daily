Repo of the day

9,229 ★

omnigent-ai/omnigent

Apache-2.0 meta-harness, open-sourced by Databricks in June, that sits above Claude Code, Codex, Cursor, OpenCode, and Pi: swap or combine harnesses without rewriting agent logic, route work across several in parallel via YAML custom agents, and enforce built-in policies — spend caps, path-scoped write access — plus sessions that follow you from terminal to browser to phone.

Why it matters: This is the layer you'd want above RealGenie's 13 agents if you ever want to swap which harness drives which agent without a rewrite, and the spend-cap/path-scoping policies are guardrails worth stealing even if you never adopt the whole thing.

Newest tools

launch

vercel-labs/fx

Vercel's new terminal coding agent, written in Zig: a Unix-shell-shaped CLI rather than a TUI/IDE-in-terminal, model-agnostic, ships as a single ~6-8MB binary built for embedding inside other agent infra.

Early and experimental (field reports say stick to small repos for now), but the embeddable, scriptable shape is closer to what you'd want inside a custom harness than a heavier IDE-style agent.

launch

XiaomiMiMo/MiMo-Code

Xiaomi's free, MIT-licensed terminal coding agent built on OpenCode. Persists state to files so multi-hundred-step tasks survive across sessions instead of losing context.

The file-backed state approach is worth copying regardless of whether you run MiMo-Code itself — durable task state is exactly what longer-running RealGenie agents need.

launch

duty1g/x64dbg-mcp-server

Native MCP plugin for the x64dbg debugger, exposing it over HTTP: 71 tools covering breakpoints, memory read/write, disassembly, PE analysis, plus 22 event callbacks. Zig, zero dependencies, single binary.

A clean reference for wrapping a stateful native desktop tool as an MCP surface — the same shape you'd reach for to give an agent control over any app that isn't already API-shaped.

A CLI toolkit for "loop engineering" with coding agents

Patterns, starters, and three CLI tools — loop-init, loop-audit, loop-cost — for designing systems that prompt and orchestrate agents in a loop, plus a GitHub Action for running loops in CI in report-only mode.

loop-audit and loop-cost are the kind of guardrails worth lifting straight into any CI pipeline that lets an agent run unattended.

3,028 ★ · GitHub

Team chat where AI agents are teammates, not a chatbox

Cross-platform chat app from the avante.nvim author: Claude Code/Codex-backed agents each get a persona, memory, and private workspace, can DM, join group chats, claim tasks, and post unprompted.

A rough model for what a human-visible multi-agent coordination surface could look like if RealGenie's agents ever need more than logs to hand off work.
