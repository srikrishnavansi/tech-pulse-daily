ApodexAI/FrontierAgent

Apodex's open-sourced agent runtime and terminal product: a native CLI TUI with ReAct mode (one stateful agent researches, edits files, runs commands, iterates) and Agent Team mode (a coordinator keeps a task board, delegates to parallel sub-agents, collects and synthesizes their reports). One-command install on macOS/Linux, no Docker dependency. Shipped alongside Apodex's open-weights model.

Why it matters: The coordinator-delegates-to-parallel-subagents pattern is exactly what RealGenie's agents do — worth a skim of how they structured the task board and the report-synthesis step in a harness they gave away for free.

GLM-5.3-Flash (Z.ai)

320B-total/18B-active MoE model, natively multimodal, 1M-token context, weights released under the MIT license (previously teased as stealth model 'Ox Alpha'). Runs on vLLM and SGLang for local deployment.

An actual runnable local option, not just an API. Early X reports (unverified, see limits) put cost around $20 per 1,000 requests and ~33 tok/s on the Flash tier, undercutting DeepSeek V4 Flash and Qwen on most workloads at the discounted API price ($0.075/M in, $0.25/M out, through ~Sep 9).
