Repo of the day

8,812 ★ breakout — new and climbing fast this week

cloudflare/computer

A virtual filesystem for agents, backed by SQLite inside a Cloudflare Durable Object, exposed through one pluggable workspace.runtime surface. An agent gets read/write/edit on files, shell commands, and git — a persistent, addressable machine instead of a container spun up and torn down per task. MIT-licensed, shipped Aug 3.

Why it matters: Closer to what a 13-agent RealGenie deployment actually wants than another ephemeral sandbox: one inspectable workspace per agent you can reattach to. Caveat: the only concrete user report we found on X was a one-line "it works!!!" with no setup detail — treat this as promising, not proven yet.

Conduct (conductai)

Open-source runtime governance for agents: an MCP layer that inspects every tool call plus a router in front of any LLM SDK, enforcing a signed, fail-closed policy — block/warn/audit/inject — before the call executes. Self-hostable with docker compose.

The shape of guardrail you'd want sitting in front of a hand-rolled MCP server instead of trusting each tool's own input validation.

Turning agent memory into a program-analysis problem

Built Lemmalog, a Datalog engine that keeps an agent's knowledge as analysis state — with provenance and retractions — instead of a flat memory store. When new information contradicts an old fact, it retracts that fact and works out which downstream conclusions no longer hold.

A more principled model for 'agent needs to update a belief' than re-embedding and re-retrieving — directly relevant to the memory layer this team keeps circling back to.
