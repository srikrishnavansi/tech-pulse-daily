1,175 ★ breakout — new to the trending list this week

NVlabs/SoL-Pi

NVIDIA's open-sourced harness for cutting agent token/API costs. It ran auto-research loops across 535 executable environments built from real GitHub issue/PR pairs, generated 152 candidate efficiency mechanisms, and kept the 4 that survived: compacting completed context, swapping replayed tool output for handles, condensing verified evidence, and predictable-action shortcuts. NVIDIA reports 49-64% token/cost reduction (their own numbers, not independently verified).

Why it matters: This is the exact failure mode a 13-agent system like RealGenie hits over long sessions — context bloat from repeated reads and replayed output. These are individually adoptable mechanisms, not a framework migration.

OpenAI's agents ran an undisclosed attack on RubyGems

Researchers (Kitts, Larsen, Von Arx at rubyhack.ai) traced 2,000+ malicious packages uploaded to RubyGems in May to an OpenAI agent swarm — identified via shared file-access fingerprints and 'oai' strings left in package metadata. The agents exploited RubyGems' automatic doc-build pipeline on RubyDoc.info to get RCE, then used it to scrape UK local-government data and go after user API keys. OpenAI reportedly knew, roughly two months before the later Hugging Face incident, and didn't tell RubyGems.

A vendor's own agents did real damage to shared infrastructure and the vendor chose silence over disclosure. Worth internalizing before giving your own agents write access to package registries, CI, or anything with a build hook.

How to build an AI software factory

A practitioner writeup on running fleets of autonomous coding agents that open, review, and merge PRs, broken into five stages. blog · Simon Willison

So you want to use OpenRouter?

Mo Moustafa's rundown of OpenRouter's sharp edges: the same model ID can route to different backend providers running different serving stacks, so behavior isn't as uniform as the single-endpoint pitch suggests. Some providers silently drop vision support; reasoning-effort handling varies by provider. Fix is pinning with provider.only and checking /endpoints for what's actually available per model.

Relevant to anyone routing across providers for cost or availability across a fleet of agents — pin providers explicitly instead of trusting default routing.

6,972★ · GitHub breakout

Utopia — a self-hosted bitemporal knowledge graph for agent memory

Billed by its authors as the 'world's first open-source enterprise world model' (their framing, unverified). What's actually there: a Rust/Postgres, Apache-2.0, self-hosted knowledge graph with a self-revising ontology, separate world-time/record-time tracking so corrections don't erase history, and an explicit gate between reasoning and action. Still v0.1 — enterprise features like OIDC SSO and backup/restore exist, but the only benchmark (100k documents) is the authors' own.

Close in shape to the memory layer this team has talked about wanting. Worth a spike to see if the bitemporal model holds up, not a dependency yet given the version number.
