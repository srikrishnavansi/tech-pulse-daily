Reverse-engineered Claude Code's hidden Antspace PaaS

Using strace, strings and objdump from inside a running Claude Code Web session, AprilNEA mapped the Firecracker microVM (4 vCPU, 16GB RAM, 252GB disk) that Claude Code Web runs in, and turned up an internal, undocumented deployment platform — codenamed Antspace — that spins up when Claude builds a web app for you on claude.ai. No exploits or privilege escalation, just standard Linux tooling pointed at the sandbox Anthropic already hands you.

This is the harness you're already trusting your agents to run inside — worth understanding the isolation boundary and deployment plumbing before building more RealGenie tooling on top of it.

Fable 5.1 cracked a 370-year-old cipher

Vals AI, an independent eval shop, had Fable 5.1 spend 44 minutes and 176K tokens on Thomas Urquhart's 1653 Cyphral Distich. The break: the cipher's 64 numbers index words in the surrounding text, and the first letters of those words spell a royalist couplet — self-verifying because each line has to land on exactly 32 letters. It then solved Urquhart's larger 285-number Cyphral Octastich the same way.

Third-party eval rather than a vendor benchmark, and the output is checkable rather than a leaderboard score — a real data point on long, unaided multi-step reasoning if you're deciding what to hand an agent versus a human.
