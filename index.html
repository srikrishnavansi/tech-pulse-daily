showlab/Show-Harness

An "Embodied Harness" that lets a VLM agent drive robots (Franka, AgileX Piper, ManiSkill, Isaac Lab) and GUIs through one compact set of discrete semantic actions instead of embodiment-specific fine-tuning: the model reasons over intent, and per-embodiment interpreter modules ground each action into actual motor commands. Ships GUMI, a browser-based way to demonstrate tasks without teleop hardware. Paper is arXiv:2609.10522.

Why it matters: Ignore the robots — the reusable part is the seam between "agent decides what to do" and "embodiment-specific layer executes it." That's the same interface RealGenie's agents need between deciding an action and calling the concrete tool/API for it, done here as a fixed vocabulary instead of a per-surface retrain.

UkisAI Swift-Qwen3.8-27B

A reasoning-efficient fine-tune of Qwen3.8-27B: identifies the specific tokens that trigger overthinking in reasoning rollouts and penalizes them during training, cutting thinking tokens 58.3% for under 1% accuracy loss and a 1.95x speedup. Savings hold at every reasoning-effort level (low/medium/xhigh). Free OpenAI-compatible API, no key required, plus GGUF/BF16/int4 builds on Hugging Face for local runs.

If reasoning-token spend is where your agent latency and cost actually go, this is a concrete recipe — and a runnable model — to benchmark against whatever you're serving now.

A 4B fine-tuned model beats Postgres's own query planner

Rohan Bansal distilled a 4B Qwen3.8 model (LoRA adapters, 21.2M trainable params) and trained it with agentic RL to call Postgres introspection tools (inspect_relation, get_column_stats, get_plan, evaluate_candidate) and emit planner hints. On the 113-query Join Order Benchmark: 1.81x geometric-mean speedup, 44.7% latency cut, zero regressions, for about $1,200 in compute. Code and write-up are both public.

It's the small-local-model-plus-narrow-tool-harness-plus-RL loop your team keeps reaching for, shipped as a full repro instead of a benchmark screenshot. His own caveat: one workload, one dataset, one machine — don't expect it to transfer to your queries untouched.

OpenSpec puts a spec layer between you and the coding agent

An openspec/ folder convention — specs/ documenting how the system actually works, changes/ holding per-feature proposals and spec deltas — that forces alignment on what and how before an agent writes code. Works with Claude Code, Cursor, Copilot and 30+ tools; lighter than BMAD, not vendor-locked like Kiro.

You already hand-roll conventions to stop agents from guessing at intent on RealGenie and ReBuddy — worth diffing this against what you've built, since it's tool-agnostic and someone else is maintaining it.

82pts · HN

DeepSeek-V4.1 Flash cuts KV cache to 890 bytes per token

A causal encoder-decoder split (20 encoder layers feeding a 20-layer decoder) projects the decoder's global KV cache from final encoder states rather than each layer's own hidden states. Combined with static per-layer attention modes (Full/Reindex/Reuse) and FP4 KV storage, the cache lands around 890 bytes/token — a 4x cut versus DeepSeek's own V4 Flash. Weights are on Hugging Face.

Their stated motivation is your problem: long-horizon agent workflows growing context and tool calls driving up prefill cost. Worth reading for the compression techniques even if you never run this model.
