Gemini 3.8 Flash

Google DeepMind's new Flash model, launched today, aimed at agentic coding and tool-use loops with more internal reasoning steps per call. Officially reported: 73.7% on DeepSWE v1.1, 54.9% on HLE-Verified, at $0.75/M input + $3.75/M output — same pricing tier as 3.7 Flash. Early testers report ~20% lower latency but also more tokens burned on hard tasks and still-present hallucinations on technical data.

Worth a spot in the routing tier as a cheap verification/judge pass in agent loops if the latency numbers hold up outside Google's own benchmarks — but this is launch-day coverage, not settled ground.
