trailhq/Graft

Maps a codebase once into a graph of linked, plain-English markdown pages (one node per system, API, or concept) and drops it into `.claude/` alongside a statusline and hooks. Instead of an agent rediscovering the codebase from scratch every session — burning tool calls and tokens re-reading files it already mapped an hour ago — it reads the graph. Install is `npm install -g @nanonets/graft` then `graft init`, no daemon required.

Why it matters: This is close to the shared-context problem across RealGenie's ~13 agents: right now each one re-derives its own picture of the codebase per run. Worth a spike to see if the graph format holds up better than ad hoc CLAUDE.md notes. Flag: the 66% vs 54% SWE-bench Verified numbers are Graft's own benchmark, not independently reproduced, and the 4x cheaper / 3x faster figures are the best single-task wins from their own sweep, not an average.

GPT-6 Astra

OpenAI's new flagship, rolled out September 3 with a 1M-token context window and native computer use (the model drives a screen like a person). API model id is gpt-6-astra, priced 2.5x GPT-5.6 Sol, available now through the API and AWS.

Computer use is the part that matters for agent work — it's a standing alternative to hand-rolled browser/desktop automation if you need an agent to operate UI that has no API. OpenAI's own "AGI" and "generational leap" framing is marketing, not a benchmark you can check — treat the reasoning-score claims the same way.

OtoDock

Self-hosted platform for running Claude Code or Codex CLI as persistent, sandboxed (bubblewrap + pasta network isolation) agent processes organized into departments that can delegate to each other or run unattended on a schedule. BYO Anthropic/OpenAI subscription or local models. Free to self-host up to 5 users; each release goes Apache 2.0 after two years.

It's a working reference for the exact problem of running many long-lived, sandboxed agents with delegation — the same shape as RealGenie's 13-agent setup, just packaged as infrastructure instead of hand-rolled.

Worth knowing

Claude Code v2.1.267

Admin-wide effort caps, plus a marketplace path-traversal fix

New `maxEffortLevel` setting caps reasoning effort across every provider (Bedrock, Vertex, Foundry) at the org level — users can go lower, not higher. Also patches a real security bug: a marketplace entry path containing a backslash could bypass the containment check for fetched marketplaces on macOS and Linux. Most of the rest of the changelog is prompt-cache reuse fixes (model switches no longer re-send every tool definition).

The marketplace containment fix is worth applying if you're pulling from any third-party marketplace for internal skills.

$998 · 43 hours

A 3.8B LLM trained from scratch for under $1,000

Hugo Vergnes built little-lm, a config-driven framework for training small decoder-only models, and used it to train a 3.8B-parameter model to 0.384 CORE on 65B tokens in 43 hours on rented B200s — his write-up says B200s beat H100s on value per unit of work for this workload.

A concrete, reproducible number for what a from-scratch small model costs outside a lab budget, useful as a reference point if a local/fine-tuned model ever looks cheaper than API spend for a narrow RealGenie task.
