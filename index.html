A rumor of a bug is enough for AI agents to find the exploit

Anil Madhavapeddy patched a path-traversal bug in OCaml's cohttp; within minutes of opening the fix PR, his web server logs showed probes matching the exact bug pattern. He then pointed his own agent at nothing but a vague description of the issue and it found the exploit unaided.

If shipping a patch now doubles as broadcasting the vulnerability to every attacker running an agent, that changes how much detail belongs in a PR or commit message for anything security-relevant you fix.

749 pts · HN

htmx 4.0 is out

Ships Idiomorph and a new <hx-partial>, but the breaking changes are the real story: XHR is swapped for fetch internally, attribute inheritance flips from implicit to opt-in via :inherited (a parent's hx-confirm no longer reaches children automatically), and history stops autosaving to localStorage by default.

Real-world upgrade reports are still thin — mostly release-note summaries plus one practitioner warning 'don't upgrade on a Friday.' Worth a canary branch before touching anything with hx-confirm or history state, not a weekend swap.
