580 ★ new repo, first 2 weeks

datawhalechina/zero-to-sglang

A from-scratch, chapter-by-chapter SGLang course co-run by Datawhale and RadixArk (the company the SGLang team founded): inference fundamentals with no GPU required, then building a mini-SGLang from scratch, then reading the real SGLang source to understand its advanced optimizations, ending in profiling, trace analysis and the full PR-submission workflow. Content is Chinese-only.

Why it matters: Most of us treat vLLM/SGLang as a box you point a checkpoint at. This is the path to understanding scheduling and continuous batching well enough to actually profile or patch the serving layer under RealGenie's agents instead of just tuning flags blind — mind the language barrier.

Newest tools

skill

i-have-adhd

A Claude Code (and Qwen Code) skill that rewrites how the agent replies: next action first, numbered steps capped at five with one bounded action each, state restated every turn, no preamble or closers. Installed via the plugin marketplace (`claude plugin marketplace add ayghri/i-have-adhd`, then `claude plugin install i-have-adhd@i-have-adhd`) and toggled on with `/i-have-adhd` for a session.

You already write Claude Code skills in-house — this is a clean, minimal example of a skill that reshapes output rather than adding capability. Worth stealing the rule set for RealGenie's agents so the answer an on-call engineer needs stops getting buried in thirteen agents' worth of narration.

local model

deltafin (Kimi K3 on a laptop)

Streams Kimi K3's full 2.8T-parameter MoE weights (1.45TB) off four SSDs into 128GB of RAM on a single M5 Max MacBook Pro, keeping only shared components resident and pulling experts on demand with router tracing and prefetch to hide read latency. Two install modes: a 215GB streaming footprint (`deltafin setup --stream`) or the full 1.7TB local copy.

1 token/sec is a proof-of-concept, not a workflow, but it's a real, working recipe for running frontier-scale MoE weights on hardware you already own rather than renting. Worth watching as SSD bandwidth and expert-prefetch tricks improve — this is the local-model story getting closer to real.

launch

GPT-5.6 Sol

OpenAI's new model, live now in ChatGPT, Codex and the API. In one published case an MIT grad student used it inside Codex to drive qubit-experiment measurement loops; separately OpenAI says the model used Codex to redesign its own draft model's architecture across hundreds of experiments, lifting token-generation efficiency over 15% — though it needed human steering whenever the experimental signal got noisy.

The self-optimizing-infra claim is the interesting part for the memory/self-improving-systems track: an agent iterating on its own serving stack is close to what a self-improving harness would actually need to do. Flagging that this is OpenAI's own writeup, not an independent eval.

show hn

LLM Attention Visualizer

A Show HN React app (built on Transformers.js) that runs a small model in-browser and lets you hover any generated token to see which prior tokens drove it — attention weight scaled by value-vector magnitude, aggregated across heads and summed across layers.

A concrete, poke-at-it way to build intuition for what a context window is actually attending to, before the next argument about prompt or context-window design in a skill or MCP server.

Worth knowing

Meta ships Muse with a sandboxed VM per agent

Meta's new consumer personal-agent app (iOS/Android/muse.ai, free plus $20 and $100 tiers) for shopping, scheduling and multi-step errands. Each user gets a dedicated cloud 'Secure VM' where the agent, its browser session and all its credentials live, isolated from Meta's own infrastructure.

The shopping-assistant framing doesn't apply to us, but the isolation pattern does: a disposable, credential-scoped VM per agent identity is a cleaner blast-radius story than most in-house tool-calling setups, including RealGenie's.

Skip this one

Inception Labs Mercury 2.5

Launched Sept 8 as 'the most capable diffusion LLM on the market' — 1,107 tokens/sec, a claimed 40% intelligence jump over Mercury 2, GPQA Diamond 79%, framed as beating autoregressive models.

Every number is Inception's own. An independent read from BenchLM.ai found only a handful of published benchmark rows, no independently measured runtime speed, and no coding or agentic benchmark results in the record at all despite the 'beats autoregressive models' pitch. It's still preview-tagged — worth another look once someone outside Inception runs it.
