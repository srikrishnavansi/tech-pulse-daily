Repo of the day

11,115 ★ new repo, all stars in the last two weeks

browser-use/jev-ultrafast

browser-use's agent rebuilt around Jev, TypeSafe's typed-decision model: instead of screenshotting the page and reasoning over it, it indexes visible controls and gets a single typed operation/target decision back in one round trip, only calling a real LLM when it needs to generate text. Their own numbers: a Zurich-to-London Google Flights search dropped from a 9.45s median to 7.09s, and browser protocol calls per task fell from 1,092 to 101 across six runs. Ships with offline tests and a local inspector; known gaps are shadow DOM, frames, canvas, and file upload.

Why it matters: This is the concrete version of the pitch behind every 'small model in the loop' idea we've discussed for RealGenie — most agent steps are a bounded choice (which listing field, which button) not open-ended generation, and routing those through a typed decision model instead of a full LLM call is a real latency and cost win, not a hypothetical one.

Newest tools

launch

trycua/cua — CUA-S1-FORMS

trycua open-sourced the first model in its own 'System One' family, built the same week as Jev's launch: a small model trained only to fill, check, click, or skip form fields from a supplied document, with the app validating and ordering the plan. MIT-licensed, weights on Hugging Face, ships with synthetic-data generation and eval code.

A second independent team shipping the same 'fast bounded model for computer-use micro-decisions' pattern within days of Jev is a signal this is a real technique, not one vendor's marketing angle — worth studying if we ever split RealGenie's UI-interaction agents into a plan/act split.

open weights

QwenLM/Qwen-Image-2.1

Alibaba's open-weight image generation and editing model, 7B parameters for the visual component, released today. Native transparent (RGBA) output, takes up to ten reference images for things like group portraits or room layouts, runs on a single 3090. Day-0 support in Diffusers and ComfyUI.

Open weights plus consumer-GPU inference means this is actually testable in-house rather than another closed API to budget against — worth a spike if any client work needs generated or edited property imagery.

unslothai/unsloth v0.1.811-beta

Docker image update plus multi-user accounts (separate logins, shared loaded model when settings match), an AMD ROCm image alongside CUDA, and a Qwen3.8-Flash-Next hotfix that's 2x faster than the prior release. Unsloth is flagging a GGUF inference-throughput regression from v0.1.810-beta, so check that before upgrading.

Multi-user Docker plus AMD support is the difference between 'one person's fine-tuning box' and something the team can actually share — relevant if anyone picks the local-fallback-model thread back up.

Worth knowing

1,266 pts · HN

Laya: an Apache-2.0 answer to Jev's typed-decision pitch

Convai's Laya is a 421M ModernBERT model that takes a typed question and returns a typed answer with a calibrated probability in a single ~33ms forward pass, trained with RL against a strictly-proper scoring rule so honest probabilities are the only way to maximize reward. Unlike Jev it's fully open (Apache 2.0), with a Rust reimplementation (laya-rs) already running sub-35ms on a plain CPU and an MLX port doing 7-14ms decisions natively on M3 Max, no PyTorch involved.

This is the open alternative to Jev worth prototyping against first — same 'typed decision, not text generation' shape for routing/classification/guardrail steps, but no vendor API dependency and no per-token bill.

305 pts · HN

Brood War Bench scores agents on real-time StarCraft

A from-scratch Brood War harness playable only by agents, run round-robin across 19 model/effort setups with wins, losses, actions-per-minute and dollar cost per game tracked. Codex Astra at xhigh effort won 18-0; the same model at medium effort and Claude Fable were close behind. Unlike most agent evals, there's no 'take as long as you like' cushion — the game clock keeps moving.

A rare benchmark that actually prices the latency/quality tradeoff instead of ignoring it, which is exactly the axis Jev and Laya are both attacking from the model side.

preview · StepFun

StepFun's Step 5: 600B MoE, weights land October 15

A 600B-parameter sparse MoE (about 27B activated per token) aimed at long-horizon agent work, with a 1M-token context window. API and pricing ($1/M input, $2.70/M output) are live now; StepFun says weights open October 15. Artificial Analysis currently scores it 44 on their Intelligence Index, well behind top frontier models.

Not worth building against yet — API-now-weights-later means no local story until mid-October, and the independent benchmark score doesn't match the framing in StepFun's own announcement.
