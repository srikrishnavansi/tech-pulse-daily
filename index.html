Repo of the day

Human-Agent-Society/reef

Continual-learning infrastructure for deployed agents: it serves agent requests, records interactions, matches user feedback back to those interactions, and turns eligible records into updates that get evaluated before publishing. Updates can target either model weights or the agent harness itself, and agents connect over standard HTTP endpoints rather than a bespoke SDK.

Why it matters: This is closer to what RealGenie's 13 agents actually need than a shared vector store — a feedback loop that can decide whether a fix belongs in the model or in the harness, with an eval gate before anything ships.

show hn

Moadim

A single Rust daemon you drop on a machine that pairs a prompt, a schedule and an agent (Claude, Codex, Hermes, and others) into a "loop." Each tick runs in a fresh, isolated tmux workbench, hung runs get killed automatically, and every loop is also a documented HTTP endpoint with an OpenAPI schema.

It's doing by daemon roughly what our own /loop skill does by hand — worth comparing its isolate-and-kill-hung-runs model against how long-running Claude Code sessions get babysat today.

HN · fresh climber

Portal cut one engineer's Claude Code token spend 90%

Spotify's internal Portal tool defines declarative "modes" — a model, temperature and set of MCP tools per task type — so routine work like bulk file reads runs on a cheap model while only the parts that need frontier reasoning hit the expensive one. Two modes, bulk-reader and code-writer, are public.

Direct pattern to steal for RealGenie's 13 agents: route by task type instead of running everything through one frontier-model config, and the savings compound fast.

Claude formalized all of Fermat's Last Theorem, unsupervised

Anthropic had an internal model run largely on its own for 11 days, producing about 13 million lines of Lean 4 and proving 30,300 intermediate theorems (about 29,500 used in the final proof) to fully formalize Wiles' proof — a job mathematicians expected to take years by hand.

A real data point on how far a single long-running agent session can go with no human checkpoints, which is exactly the tradeoff to weigh before giving RealGenie or ReBuddy agents a long leash on a job.

Actively exploited sandbox RCE in every Chromium build

CVE-2026-85046 is a sandbox-escape RCE affecting all current Chromium versions and is being exploited in the wild; the NVD entry is live and patches are rolling out.

Any browser-driving agent (Playwright/Puppeteer harnesses, browser-extension agents) inherits this until its Chromium is patched — check the pinned version in your sandboxes this week, not next sprint.
