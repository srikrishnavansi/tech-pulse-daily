Open-source alternative to Paper.design: a multiplayer design canvas where humans edit in the browser and AI agents edit through a built-in MCP server, streaming frames onto a shared canvas live with visible cursors, presence and per-agent status. AGPL-3.0.

Newest tools

launch

huggingface/kernels

Hugging Face shipped 207 WebGPU kernels to the Kernel Hub, extending the existing CUDA/ROCm/Metal kernel set into the browser. Kernels are versioned, benchmarked packages rather than vendored code; the team is working with the ONNX Runtime project to upstream this into ONNX Runtime Web.

A real building block for a local or browser-side inference fallback for RealGenie or ReBuddy, instead of hand-rolling WebGPU ops or provisioning a GPU box for a prototype.

skill

nateherkai/scroll-craft

A Claude Code skill for scroll-driven websites that picks from eight incompatible page layouts instead of reaching for one template, then verifies its own output with a headless-browser pass that screenshots the rendered scroll to catch dead scrolling, low contrast and broken video.

The self-screenshot verification loop is the reusable idea here — a skill checking its own rendered result before declaring done is a pattern worth stealing for our own SKILL.md files.

An AI-written Python tracing library, human-architected

Graham Dumpleton (wrapt, mod_wsgi, New Relic's Python agent) built wrapture, a function/method wrapper for tracing and overriding return values. Every line of code and docs was written by an AI assistant under his direction — he designed the result, the model produced it.

A clean example of scoping an AI's role to implementation while a domain expert keeps the design — the same split we're trying to hold onto when pointing Claude Code at unfamiliar internals.
