Newest tools

launch

mezmo/aura

Rust SRE agent, Apache 2.0, that connects to logs/metrics/traces and runs a detect-anomaly → gather-context → propose-fix → execute loop with configurable approval gates. Agents are composed declaratively in TOML and the provider is swappable across OpenAI, Anthropic, Bedrock, Gemini, Ollama and OpenRouter. It's the same codebase Mezmo runs in their own production clusters.

A concrete reference for the approval-gate and provider-swap plumbing that a production incident-response agent needs — worth diffing against however RealGenie's harness currently handles tool permissions.

Qwen 3.8 27B on Cerebras

Cerebras added Qwen 3.8 27B to its public inference catalog at roughly 1,500 tokens/sec with a 128k context window on the paid tier (64k free). It's the unpruned, original weights — Cerebras publishes pruned versions separately on Hugging Face for research.

An open-weight model with a genuine local/self-host story, now also available as a fast hosted endpoint — a real option for a low-latency fallback path instead of a theoretical one.

Which tools do Claude, Codex and Cursor choose? 17k runs measured

Armature ran 16,893 sessions across 1,163 prompt variations and 75 repos with Claude Code, Codex and Cursor actually implementing solutions (not just recommending one), then published the full traces — prompts, thinking, diffs — alongside leaderboards.

Raw traces of what tools three major harnesses reach for under real prompts is a better diffing source for skill/tool design than another benchmark table.

36pts · HN

Grep beats LSP: why coding agents ignore the fancier tool

Claude Code, Codex CLI, OpenCode, Cursor, Continue and Aider all default to grep/ripgrep for exploratory code search over LSP, even where LSP support exists (Claude Code added it in v2.0.74). The argument: grep is cheap, broad-coverage search; LSP is precise but narrow, better as a confirmation step than a first move.

Directly relevant if you're tuning tool priority in a custom harness or skill — the layered pattern (grep first, LSP to confirm) is the one worth copying.

305pts · HN

Google Antigravity bans accounts for third-party tool use

Google has been suspending Antigravity access — including paid $250/mo Ultra subscribers — for routing traffic through third-party tools or proxies, most notably OpenClaw, that connect via Antigravity OAuth tokens. Only Antigravity access is affected, not the whole Google account, but enforcement has hit users who say the prohibited behavior wasn't clearly documented.

Worth knowing before wiring any Antigravity credentials into a custom integration or proxy — the ToS boundary is being enforced retroactively and without much warning.

Skip this one

GPT-6 Astra's 99.95% ARC-AGI-3 score

Astra is being quoted at 99%-99.95% on ARC-AGI-3, above the human action-efficiency baseline on 96% of levels.

That number only appears with OpenAI's own Provider Adapter, which preserves reasoning state across turns. On the standard/neutral harness the same model scores 62.7%. It also still trails Fable 5.1 on the Intelligence Index and Opus 5 on the Coding Agent Index in third-party evals. Quote the neutral number, not the adapter-assisted one.
