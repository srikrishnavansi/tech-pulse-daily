Gemma 4 26B fits in 2GB of RAM

X research came back empty this run — every query hit the same exhausted-credits error — so this one leans on GitHub and HN. The standout is a repo that streams a 26B MoE model's experts off SSD to run it on a laptop.

Repo of the day

6,664 ★

drumih/turbo-fieldfare

Runs the instruction-tuned Gemma 4 26B-A4B MoE model without loading the full 14.3GB into memory: keeps a 1.35GB shared core plus the FP16 KV cache resident, then streams only the experts each token needs from SSD. Swift/Metal runtime, CLI and native Mac app, Apache 2.0, weights pulled separately from the pinned Hugging Face checkpoint. Needs an M-series Mac with 8GB+ RAM; image input wants M2 or newer.

Why it matters: A real local-fallback story for RealGenie's agents if the streaming-experts approach holds under sustained load — a 26B model that fits alongside everything else already running on a laptop, no dedicated GPU box required. We couldn't get independent practitioner reports on throughput or stability this run (see limits), so treat the RAM claim as repo-stated until someone here spikes it.
