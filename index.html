Repo of the day

638 ★ new — breakout repo this week

furkankly/zoetrope

Reads a Claude Code session's local JSONL transcript and renders it as a live flow graph — main agent, subagents, tool calls — in the terminal or browser, with zero network calls anywhere in the dependency tree. Timeline scrubbing, jump-to-prompt, snap-back-to-live. Install via `brew install furkankly/tap/zoetrope`, or drag a transcript into the browser app to replay it fully locally.

Why it matters: We debug multi-agent sessions by staring at raw JSONL today. This is a genuinely different way to see what 13 agents are doing at once. X coverage so far is demo posts only, no real day-to-day user reports yet — worth trying, not yet proven.

Anthropic Model Hardware Standard (research preview)

A protocol for letting an agent control physical hardware directly — microscopes, robotic arms, lasers, liquid handlers — the physical-world counterpart to MCP. It's model-agnostic and reachable from any harness over standard protocols including MCP. Launch partners include AWS, Universal Robots, Hugging Face LeRobot and Raspberry Pi. Access is waitlist-only right now (modelhardwarestandard.com); Anthropic says it will open-source the standard after the safety review.

Not something to run this week, but the shape is worth watching if we ever need an agent to touch real building systems rather than just their software APIs.

60-80% ASR · independent research

Claude Code Auto Mode broken by indirect prompt injection

Auto Mode — the classifier-based approval system that replaced manual permission prompts and has been Claude Code's default since mid-August — was hit with a targeted attack chain starting from an ordinary 'summarize this website' request, reaching 60-80% attack success to code execution in a small-sample test. That directly contradicts the 0.00% attack success rate from the third-party eval Anthropic commissioned for the same feature.

If Auto Mode defaults are on anywhere in our harnesses, this is the reason to go re-read what the safety classifier actually catches versus what it was benchmarked against.
