Repo of the day

1,467 ★ new breakout repo — no weekly delta reported

amosblomqvist/learn

A personal AI tutoring system built entirely as a Claude Code skill: one teaching skill plus three subagents — researcher (fact-checks material before it's taught), svg-maker and mermaid-maker (generate diagrams on demand). It ships a graded quiz extension and a UI-popup extension for mid-lesson questions, and runs fine without the subagents too — you just lose the fact-checking pass and the generated visuals.

Why it matters: It's a clean worked example of the skill-orchestrates-subagents pattern you're already using in RealGenie: one skill delegating to narrow, single-purpose subagents with an explicit verification step before anything ships. Worth reading for the researcher subagent's fact-check design alone.

GPT-6 Astra (OpenAI)

OpenAI's new flagship model, previewed to partners September 3 and rolling out this week to ChatGPT paid tiers, the API, and AWS Bedrock. Headline feature is computer-use — the model driving a computer directly instead of through narrow tool calls.

Computer-use is the same territory as RealGenie/ReBuddy's tool-calling agents — once API access lands, worth a real side-by-side on your own tasks rather than taking the launch at face value. Treat the 'beats Claude Fable 5' comparisons as OpenAI's own scores: it's a closed model, no published weights or eval code.

launch

Lanes Link (Personal Context MCP)

Self-hostable MCP server that connects your accounts, memory, and skills once, then exposes them to every agent you use through Access Profiles you define — so switching agents doesn't mean reconnecting tools or re-explaining your setup. Open source; run it locally, in your own cloud, or on their managed cloud.

This is the memory-portability problem you'd hit scaling RealGenie's 13 agents or handing work between Claude Code and other tools — one identity/context layer instead of thirteen ad hoc ones.

Worth knowing

BerriAI/litellm v1.100.0

LiteLLM adds Claude 4.6 thinking-budget passthrough

Keeps a caller's thinking.budget_tokens intact for Claude 4.6 on /v1/messages via a new supports_legacy_thinking flag, adds access-group budgets and custom router tiers, and syncs Together AI pricing. Two breaking changes: router_model_name is gone from auto-routed responses (use return_raw_model_name instead), and the proxy-wide autorouter_savings_baseline_model setting is deleted.

If ReBuddy or RealGenie proxy through litellm, the router_model_name removal will silently break anything reading that field — worth a grep before upgrading.
