Repo of the day

2,226 ★ 445 → 2,226★ in ~18h

yanliudesign/mono-color-skill

A Claude Code skill — not a single prompt — that turns a theme, sentence, object, or reference photo into an editorial one- or two-ink print image: one dominant plate plus a narrow accent, halftone photography, active negative space, restrained serif/grotesk type. People on X report running it via Claude Code and WorkBuddy for city posters, personal-photo conversions, and museum-exhibition graphics.

Why it matters: Worth reading as a SKILL.md pattern: instead of one style prompt, it encodes a full rule system — recipes, examples, evaluation criteria — that reproduces a specific look on demand. That's the same consistency problem as making a RealGenie agent's output repeatable across runs, just applied to images instead of text.

hkqr/my-free-code

Open-source multi-provider AI gateway that sits in front of Claude Code and other coding agents — routes across providers, and handles streaming, tool calls, reasoning-mode passthrough, fallbacks, and local models.

Same shape as the routing-across-providers-and-local-models problem worth solving once in the harness rather than per-project — a reference before rolling another one by hand.

launch

sodiumsun/agenttrail

An infinite, zoomable canvas where every repo is a region and you watch your coding agents move through them live — a spatial map instead of a stack of terminal scrollbacks.

RealGenie runs about 13 agents at once; a live view of who's doing what is the gap between staring at 13 log tails and an actual dashboard.

Worth knowing

52pts · HN

Google Antigravity ships a /boost deep-reasoning loop

Slash command that kicks a task into a multi-agent reasoning loop: agents investigate in parallel, an orchestrator validates the combined fix against the full test suite, failures get fed back for another pass, and you get a summary of verified changes.

The orchestrator-validates-against-tests-then-feeds-back-failures loop is the part worth comparing against however RealGenie's agents currently self-correct, independent of whether Antigravity itself is in play.

v2.1.252 · release

Claude Code patches a macOS crash and a permission-save bug

Fixes a 'task output swap refused' error on some Macs, makes 'always allow' actually persist in projects that don't yet have a settings.local.json, stops Remote Control sessions stalling for minutes on degraded connections, and fixes an API request-size crash from very large failure output.

If 'always allow' has silently not been saving for you, this is the release that fixes it.

21pts · Show HN

SlideOps flags slides that drift from the code

Generates slides from a repo and re-checks them against the codebase on an ongoing basis, flagging slides that have gone stale as the code moves on.

Same drift problem as a SKILL.md or README describing behavior the code no longer has — a pattern worth stealing for keeping our own docs honest as agents rewrite the code under them.
