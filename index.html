Repo of the day

6,613 ★

genspark-ai/genoffice

Open-source Office suite — Word, Excel, PowerPoint, PDF, Markdown and HTML editors, each with a built-in AI agent. Edits real .docx/.xlsx/.pptx files, converts PDF to Word on-device, and is BYOK: plug in a Claude, OpenAI, Gemini or DeepSeek key. Documents stay local; only the AI calls leave the machine.

Why it matters: A concrete reference for agent-in-the-loop document editing — local-first app, pluggable model key, embedded tool loop. Close to what a RealGenie-style lease/contract editing assistant would need, minus the multi-agent orchestration.

Newest tools

launch

AgentsDock

Desktop and mobile client that puts Claude Code, Codex and Cursor into one workspace, talking to an AgentsServer you run on the machine that actually has your repos and CLIs.

A concrete stab at checking a long-running Claude Code session from your phone instead of tmux-over-SSH — worth trying before anyone builds an in-house version of the same thing.

launch

Toast

Single ~28MB Go binary that's a batteries-included terminal IDE: managed LSPs (gopls, rust-analyzer, pyright, typescript-language-server), tree-sitter highlighting, tabs, file tree, markdown preview. `brew install paradise-runner/tap/toast`.

Useful for reviewing what an agent changed from a bare terminal — SSH box, container, remote dev env — without hand-rolling an nvim config first.

launch

GPT-6 Astra / ChatGPT Work

Simon Willison had ChatGPT Work (on GPT-6 Astra) plan running routes: it ran autonomously for 27 minutes, called Nominatim and Overpass for OSM data, computed loops, then rendered a D3 map plus downloadable GPX/GeoJSON through a 'visualize' skill sandboxed to a CDN allow-list (jsdelivr, cdnjs, esm.sh, unpkg, fonts).

The routes aren't the point — Willison couldn't see the code or steps the agent actually ran, only the output. That's the exact failure mode to design against in your own skills: log tool calls, don't trust the artifact alone.
