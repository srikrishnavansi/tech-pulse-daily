Decision models, not chat models, are trending

TypeSafe AI's Jev returns typed, calibrated answers in a single forward pass instead of generating text, and an open clone of the idea is now GitHub's top-trending repo. Elsewhere: a coordination protocol for parallel coding agents, Xiaomi's open-weights MiMo-V2.6 topping the open-model leaderboard, and a live supply-chain attack hiding in an npm math package.

Repo of the day

11,711 ★ ~3.9K stars two days after creation, 11.7K today

NandhaKishorM/laya

A non-autoregressive decision engine, in the same 'System One' shape TypeSafe AI's Jev popularized this month: feed it a state (text, email, ticket, JSON) plus a typed question — a choice, a score, a yes/no — and it returns a calibrated answer in one forward pass, ~7ms/question batched on a T4. No token generation, so there's nothing to parse and nothing to hallucinate. A built-in router auto-detects language and dispatches to the right checkpoint. Apache 2.0, Python.

Why it matters: This is what belongs behind the routing and classification calls scattered across RealGenie's 13 agents — 'which agent should handle this', 'is this ticket urgent' — the decisions that don't need a full LLM round-trip. Worth a spike swapping one of those out and timing it.

Newest tools

launch

naw103/foremerge

Open-source coordination protocol, built above Git, for parallel coding agents. Agents keep isolated worktrees but publish intent and claim semantic scopes before writing code, so two plans that can't both be true collide in a queryable store instead of in your merge. No hard locks, no LLM in the detection path — findings are advisory. Pre-1.0 (v0.4/0.5), local-first.

This is the exact failure mode multi-agent coding setups hit once you run more than two agents on the same repo — one undoes another's work without ever touching the same file. Worth trying against whatever coordinates our own parallel agent runs today.

GA

Cloudflare Python Workers

Python on Cloudflare Workers is now GA — real Python, not a transpile, running at the edge with the same deployment model as JS Workers.

A plausible cheap host for small MCP servers or webhook-triggered agent tools that don't need a full backend.

open weights

Xiaomi MiMo-V2.6

Open-weight release in Pro (1.02T total params, ~42B active) and Flash (309B total, ~15B active) sizes, MIT-licensed, 1M-token context, native multimodal. Pro currently tops Artificial Analysis's open-weights Intelligence Index. Xiaomi also open-sourced 7,000+ RL environments and its training stack under the same license.

The strongest fully-open model available right now if we ever want a self-hosted fallback tier instead of leasing everything from a closed API.

Linear reworked CI because AI-written code made it the bottleneck

Their test suite nearly quadrupled in 2026 while agents kept shipping. Fixes: switched tsc for the native tsgo compiler (cut the weekly median tsc check 73%), moved off GitHub Actions to faster runners, rewrote lint rules to skip full type-graph builds, doubled Vitest sharding, and cut context sent to agents by 40% through context engineering.

A concrete checklist for the same problem we'll hit as agent-generated diffs scale faster than review and CI can absorb them.

121pts · HN

An npm math package shipped an encrypted remote-access loader

SafeDep found mathmain, a mathjs clone, hiding an AES-256-GCM-encrypted payload that only decrypts and runs when its lusolve() function is passed one specific 3x3 matrix — dormant for everyone else. It and two sibling packages pulled 3.1M downloads in a week before being caught.

A reminder that install counts and passing tests don't rule out a payload that only fires on a narrow trigger — relevant every time we pull a new dependency into an MCP server or skill.

HF blog · arXiv

Pruning LLMs like a physicist

Frames which transformer blocks to delete as an Ising-glass energy minimization instead of greedy heuristics, using a second-order Taylor expansion to account for interactions between blocks. At 50% compression of Llama-3.3-70B-Instruct it lands ~23 MMLU points above prior block-removal methods, and transfers without retraining to hybrid Mamba/attention/MoE architectures.

If we ever want to shrink a self-hosted model (MiMo-Flash, a Llama checkpoint) for local fallback, this is a better starting point than naive layer dropping.

129pts · HN

Tim Dettmers' lab open-sources a week of local-AI tooling

Two frameworks and four papers under the theme 'frontier AI on hardware you own', including CliffCompaction — an auto-compaction technique for cutting agent context/token costs that the lab claims beats what Claude Code and Codex do today — plus tooling for efficient autonomous research agents on single-node consumer hardware.

Auto-compaction for long-running agent context is exactly the kind of thing worth stealing for our own harness instead of hand-rolling a worse version.
