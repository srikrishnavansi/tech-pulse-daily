Repo of the day

739 ★

cbrock84/headcount

An entire company structured as Claude Code plugins: 15+ departments, 125+ skills, each independently installable so a project only loads what it needs. Skills are namespaced department:skill (security:threat-modeling, finance:unit-economics) so names never collide, every department ships an agent charter under .claude/agents/ so it can be delegated to as a subagent with its own exclusive write surface, and Security/Legal review other departments' commits with blocking findings the reviewed department can't overrule.

Why it matters: This is a concrete answer to the problem RealGenie's ~13 agents already have — namespacing skills, giving each agent a bounded write surface, and having some agents' findings actually block others instead of just advising.
